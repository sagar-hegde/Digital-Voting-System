# 🗳️ DigiVote – A Digital Voting System

> A secure, scalable, and role-based **Digital Voting Web Application** designed to simulate real-world election systems with authentication, poll management, and admin governance.

---

## 🚀 Live Demo

🔗 *https://dgvote.netlify.app*

---

## 📌 Overview

**DigiVote (Digital-Voting-System)** is a full-stack web application that enables seamless digital voting with **real-time data handling**, **secure authentication**, and **role-based system control**.

The system is designed to handle **multiple user roles**, enforce **data integrity**, and ensure **fair voting practices** using structured backend logic.

---

## ✨ Key Features

### 🔐 Authentication & Security

* Mobile-based login using **10-digit number + password**
* Unique **Voter ID generation (ABC12345 format)**
* Duplicate voting prevention logic
* Role-based access control (RBAC)

### 👥 Multi-Role System

* **Voter** → Vote in active polls
* **Candidate** → Create & manage polls
* **Admin** → Full system governance

---

## ⚙️ Core Functionalities

### 👤 Voter Module

* Register/Login via mobile
* Generate unique voter ID
* View active polls
* Cast vote securely

### 🧑‍💼 Candidate Module

* Create polls with date scheduling
* Manage existing polls
* Edit/Delete functionality

### 🛡️ Admin Module

* User management (Voter/Candidate)
* Poll moderation
* Access control & monitoring
